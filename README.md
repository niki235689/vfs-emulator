# VFS Shell Emulator (Вариант 21)

Эмулятор командной оболочки операционной системы с GUI интерфейсом
и виртуальной файловой системой в оперативной памяти.

## Описание функций и настроек
- **GUI интерфейс**: заголовок формируется динамически: `Эмулятор [user@host]`.
- **Парсер**: поддерживает одинарные и двойные кавычки.
- **Команды**:
  - `exit`: завершение сессии.
  - `ls [args]`: заглушка команды листинга.
  - `cd [args]`: заглушка смены каталога.
  - `conf-dump`: вывод конфигурации (`ключ=значение`).
- **Параметры запуска**:
  - `--vfs <path>`: путь к физической папке источника VFS.
  - `--script <path>`: путь к стартовому скрипту.

## Команды сборки и запуска

Запуск приложения:
```bash
bash run.sh --vfs vfs_samples/deep --script scripts/startup_stage2.txt
